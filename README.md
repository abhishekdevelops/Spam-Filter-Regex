# 🛡️ Spam Filter using Regular Expressions

A JavaScript project that filters spammy or unwanted content from user input using **regular expressions**.  
Built as part of the **freeCodeCamp JavaScript Algorithms and Data Structures Certification**.

## 💡 Features
- Built using HTML, CSS, and JavaScript
- Detects spam phrases using RegEx patterns
- Learn concepts like:
  - Capture groups
  - Positive lookaheads
  - Negative lookaheads
  - Character classes
- Real-time input checking with dynamic feedback

## 📘 Overview
Regular expressions (RegEx) are patterns used to match character combinations in strings.  
This project helps you understand and practice:
- Validating text input with complex rules
- Writing RegEx for typical spam keywords
- Replacing or flagging matches in real-time

### 🔍 Example
Detect and flag inputs like:
- `win a free iPhone`
- `click here now`
- `make $$$ fast`

Using patterns like:
```js
let pattern = /free|click\s+here|make\s+\${3}/gi;
```
